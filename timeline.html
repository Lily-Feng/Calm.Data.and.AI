Authoring

Adding a timeline

1 · Write the data

One JSON file in data/timelines/. Stamps carry their own precision, so 1936, 2026-08-24, and 06:40 all sit on the same axis machinery.

2 · Weight the entries

A weight from 0 to 1 sets the tier, which sets the marker size, the card width, and whether the entry reads as a landmark.

3 · Call the component

createTimeline(mount, spec) — see js/timeline-page.js. Nesting a children block on an entry gives it a sub-timeline, drawn by the same function.
