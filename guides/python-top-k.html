Representative problem

Return the k most frequent values in a large stream. Explain the trade-off between a heap and bucket sort.

Reasoning model

How to approach it

  1. Count frequencies when the input is finite; for a stream, update counts incrementally.
  2. Maintain a min-heap of at most k frequency/value pairs.
  3. Replace the smallest candidate when a better one appears.
  4. State when bucket sort is preferable: bounded integer frequencies and O(n) extra space.
Failure modes

What breaks the model

  • Using a max-heap of all n values and losing the space advantage.
  • Ignoring stable or tie-breaking requirements.
  • Calling the approach streaming when exact changing counts require updates or recomputation.
Core synthesis

What to remember

A size-k min-heap keeps the current threshold at the root. After counting m unique values, each candidate costs at most O(log k), so total work is O(n + m log k) and heap space is O(k). Bucket sort can be O(n), but allocates buckets by frequency and is less flexible when the score is not a small integer.

python reference 
from collections import Counter
import heapq

def top_k(nums, k):
    heap = []
    for value, count in Counter(nums).items():
        heapq.heappush(heap, (count, value))
        if len(heap) > k:
            heapq.heappop(heap)
    return [value for _, value in heap]
