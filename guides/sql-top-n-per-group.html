Representative problem

Return the three highest-paid employees in each department, including deterministic tie handling.

Reasoning model

How to approach it

  1. Define the group with PARTITION BY department.
  2. Define rank order with salary descending and an explicit tie-breaker.
  3. Choose ROW_NUMBER, RANK, or DENSE_RANK based on the tie requirement.
  4. Filter the rank in an outer query or QUALIFY where supported.
Failure modes

What breaks the model

  • Using LIMIT, which applies to the whole result.
  • Leaving ties nondeterministic.
  • Filtering before ranking and changing the population.
Core synthesis

What to remember

This is a window-function problem because I need row detail and a calculation within each department. ROW_NUMBER gives exactly three rows when I add a stable tie-breaker. If the business wants all people tied for third, I use RANK or DENSE_RANK and explain the difference in skipped rank numbers.

sql reference 
WITH ranked AS (
  SELECT
    employee_id, department_id, salary,
    ROW_NUMBER() OVER (
      PARTITION BY department_id
      ORDER BY salary DESC, employee_id
    ) AS position
  FROM employees
)
SELECT *
FROM ranked
WHERE position <= 3;
